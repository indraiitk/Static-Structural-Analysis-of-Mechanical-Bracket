# Static Structural Analysis of Mechanical Bracket

## Project Overview
Static structural analysis of a mechanical bracket was performed
using ANSYS Workbench. The analysis was carried out to evaluate
the structural response of the bracket under the applied loading
and boundary conditions.

## Software Used
- ANSYS Workbench
- Autodesk Inventor
- MATLAB

## Analysis
- Total Deformation
- Equivalent (von-Mises) Stress
- Equivalent Elastic Strain
- Factor of Safety
- Strain Energy

## MATLAB Verification
The ANSYS results were verified using a MATLAB-based calculation.

- ANSYS project files
